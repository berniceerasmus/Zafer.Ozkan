📐 Grammar at a glance

There is / There are

There is + singular / There are + plural

Saying what exists or is present somewhere.

There is a car park behind the clinic. / There are three shelves here.

Some / Any

some (+ / offers), any (- / ?)

Talking about quantities.

I have some catalogues. / I don't have any catalogues left.

Prepositions of Place

next to, opposite, between, near, behind

Describing where something is located.

The lab is behind the main building.
